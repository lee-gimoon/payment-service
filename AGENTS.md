# Project instructions

For changes to the React UI in `frontend/`, read the root `DESIGN.md` and follow its visual and payment-copy rules. Use `frontend/src/styles.css` as the source of truth for currently implemented styles. Update `DESIGN.md` when intentionally changing the visual system.

The design guide applies to the frontend only. Follow `README.md` and the relevant `docs/` pages for payment behavior and backend changes.
