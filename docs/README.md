# 프로젝트 문서

프로젝트 소개와 시작 명령은 [루트 README](../README.md)에 있습니다. 아래 문서는 현재 구현의 계약과 유지보수에 필요한 내용을 다룹니다.

| 문서 | 읽을 때 |
| --- | --- |
| [아키텍처](architecture.md) | 도메인 규칙, 상태, 트랜잭션과 복구 정책, 설계 결정을 확인하거나 변경할 때 |
| [결제 도메인 그림](payment-domain-target.png) | 주문당 결제 1건을 지키는 흐름을 한눈에 볼 때 |
| [API](api.md) | 클라이언트를 연동하거나 요청·응답 계약을 변경할 때 |
| [설정](configuration.md) | 토스 키, DB 연결, 결제 복구 작업, 개발 서버 주소를 설정할 때 |
| [개발 가이드](development.md) | 테스트·빌드·마이그레이션을 수행하고 변경을 제출할 때 |
| [UI 디자인 기준](../DESIGN.md) | 현재 화면의 스타일·결제 문구를 수정할 때 |

API의 필드 스키마는 실행 중인 서버의 [Swagger UI](http://127.0.0.1:8080/swagger-ui.html)에서 확인합니다. 구현을 바꿀 때 관련 문서도 같은 변경에서 갱신합니다.
