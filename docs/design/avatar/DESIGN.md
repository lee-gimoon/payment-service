# MODO CLUB · 아바타 티셔츠 쇼핑몰 디자인 제안

이 문서는 티셔츠 10종 상품 목록의 시안과 구현 방향을 정의한다. 현재 React 화면의 기준은 프로젝트 루트의 [`DESIGN.md`](../../../DESIGN.md)와 `frontend/src/styles.css`다. 실제 화면은 이 방향으로 구현되었으며 SVG는 배치 참고용 정적 시안이다.

참고한 [awesome-design-md](https://github.com/VoltAgent/awesome-design-md)는 하나의 정해진 외관이 아니라, 여러 사이트의 디자인 언어를 `DESIGN.md`로 기술한 사례 모음이다. 그 저장소의 문서 구성 방식인 분위기·역할별 색상·타이포그래피·컴포넌트·반응형 규칙을 참고해 이 프로젝트만의 캐릭터 쇼핑몰 디자인을 작성했다. 특정 브랜드의 로고나 외관을 복제하지 않는다.

## 1. Visual Theme & Atmosphere

- 콘셉트: **캐릭터 아바타가 옷을 입어보는 쇼핑몰**. 랜딩에는 아바타 한 명을, 목록에는 티셔츠 상품 10개를 놓는다. 사용자가 고른 옷을 아바타에 적용하는 흐름이다.
- 상품 목록 이미지는 옷 자체를 보여준다. 아바타는 랜딩과 선택한 옷을 입어보는 화면에 표시한다. 실사 모델이나 사람 사진은 쓰지 않는다.
- 밝고 장난스러운 색을 쓰되, 상품명·가격·선택 상태는 차분하고 또렷하게 표시한다.
- 브랜드 가칭은 `MODO CLUB`이다. 이름과 상품 정보는 시안용이다.

## 2. Color Palette & Roles

| 역할 | 색상 | 사용처 |
| --- | --- | --- |
| 배경 | `#fffdf7` | 페이지 바탕 |
| 글자 | `#23243a` | 제목·가격·중요 정보 |
| 기본 동작 | `#4258e7` | 주요 버튼·활성 강조 |
| 부드러운 파랑 | `#e9eeff` | 히어로·정보 배경 |
| 보조 글자 | `#70748d` | 설명·상품 속성 |
| 구분선 | `#dce0eb` | 카드·섹션 경계 |
| 새 상품 강조 | `#ff816d` | NEW·BEST 배지 |
| 상품 배경 | 상품별 파스텔 | 티셔츠 색과 패턴이 드러나는 상품 이미지 영역 |

상품색은 배경색과 구분되어야 한다. 선택 상태를 색상만으로 전달하지 않고 체크·텍스트·테두리를 함께 제공한다.

## 3. Typography Rules

- 한글과 영어가 모두 읽히는 시스템 산세리프를 기본으로 한다.
- 브랜드명은 굵고 짧게, 메인 제목은 큰 크기로 쓴다. 상품 카드에서는 상품명과 가격을 명확히 분리한다.
- 영문 속성 표지는 보조 정보로만 쓴다. 구매 결정에 필요한 상품명·가격·사이즈는 한국어로 표시한다.
- 모바일에서 상품명은 13px 이상, 가격은 13px 이상, 주요 버튼은 11px 이상으로 시작한다. 실제 구현에서는 기기별 가독성을 검증해 상향한다.

## 4. Component Stylings

- **아바타 미리보기:** 랜딩에서는 한 캐릭터에 선택된 티셔츠 한 벌을 보여준다. 옷을 고른 뒤 같은 아바타에 적용한다.
- **상품 카드:** 캐릭터 없이 티셔츠 한 벌의 색·패턴·프린트를 보여준다. 상품마다 배경색을 달리해 탐색을 돕는다.
- **상품 정보:** 일러스트 아래에 영문 속성, 한국어 상품명, 원화 가격 순으로 배치한다. 색상과 상세 옵션은 별도 텍스트로 제공한다.
- **필터:** 선택된 항목은 진한 표면과 밝은 글자로 표시하고, 키보드 포커스와 개수를 함께 제공한다.
- **버튼:** 기본 동작은 파랑, 보조 동작은 밝은 표면. 비활성화·로딩·포커스 상태를 구분한다.
- **배지:** `NEW`, `BEST`는 상품 설명의 대체 수단이 아니다.

## 5. Layout Principles

- 데스크톱: 상단 탐색, 아바타 한 명이 있는 히어로, 필터, 티셔츠 상품 5열 × 2행. 이미지 영역과 상품 정보의 높이를 일정하게 유지한다.
- 모바일: 상단 탐색, 아바타 한 명이 있는 히어로, 간결한 필터, 티셔츠 상품 2열 × 5행.
- 카드 사이 여백은 데스크톱 15px 이상, 모바일 20px 수준을 기준으로 한다. 상품 정보가 카드 밖으로 넘치지 않게 한다.
- 실제 구현에서 좁은 화면의 터치 대상은 최소 44×44px 수준으로 확인한다.

## 6. Depth & Elevation

- 기본 화면은 테두리와 색면으로 층위를 만든다. 카드에 무거운 그림자를 반복하지 않는다.
- 아바타와 옷 일러스트에 부드러운 그림자를 사용해 형태를 구분한다.
- 배경의 원형 장식은 히어로와 상품 무대에 한정한다.

## 7. Do's and Don'ts

- 상품 10개는 10개의 룩이나 10명의 아바타가 아니라 10개의 옷 목록이다.
- 랜딩의 주요 버튼은 **`룩 보기`**라고 쓴다. 상품 개수를 버튼 문구에 넣지 않는다.
- 사용자가 고른 상품을 한 아바타에 입혀볼 수 있게 한다.
- 상품마다 옷의 색뿐 아니라 프린트·스트라이프·포켓 같은 디자인 차이를 보여준다.
- 사람 사진이나 쇼핑몰 템플릿의 익숙한 패션 화보 느낌으로 되돌리지 않는다.
- 캐릭터 장식 때문에 가격·옵션·장바구니 동작을 가리지 않는다.
- 상품명·가격·재고가 서버 데이터로 바뀌어도 레이아웃이 유지되도록 한다.

## 8. Responsive Behavior

- 700px 이하에서는 탐색을 축약하고 히어로의 문구를 아바타보다 먼저 읽게 한다.
- 필터는 가로 스크롤 또는 접기 UI로 구현한다. 보이지 않는 옵션이 있다는 힌트를 제공한다.
- 긴 상품명·금액은 줄바꿈을 허용하고 버튼과 겹치지 않게 한다.
- 장바구니·상세 화면을 구현할 때 모바일에서도 아바타 착장과 주문 정보를 함께 이해할 수 있어야 한다.

## 9. Agent Prompt Guide

> `docs/design/avatar/DESIGN.md`와 PC·모바일 SVG 시안을 기준으로, 랜딩에는 아바타 한 명과 `룩 보기` 버튼을, 상품 목록에는 옷 이미지 중심의 티셔츠 10개를 배치해 주세요. 상품을 고르면 그 옷을 아바타에 입혀보는 흐름으로 만드세요. 상품명·가격은 서버 상품 API에서 받고 실제 결제 금액은 서버 주문 응답을 사용하세요. 테스트 결제 및 최종 승인 안내를 유지하세요.

결제 흐름은 루트 `DESIGN.md`의 문구 규칙을 적용한다. 테스트 키 결제는 실제 청구되지 않음을 알리고, 결제수단 인증 성공과 서버 최종 승인 완료를 구분한다.
