# 이전 설계 자료

이 폴더는 이전 설명 자료를 보관합니다. 현재 구현과 API 계약은 [아키텍처](../architecture.md)와 [API 문서](../api.md)를 기준으로 확인합니다.

## 결제 도메인 이미지

[기존 결제 도메인 이미지](payment-domain-target.png)는 README와 아키텍처 문서에 사용했던 설명 자료입니다. 현재는 아키텍처의 Mermaid 흐름도와 상태·복구 설명으로 대체했습니다.

다음 표현은 현재 구현을 설명하는 데 적합하지 않아 원본을 현재 문서에서 분리했습니다.

- “어떤 일이 생겨도 실제 결제는 한 번”: 중복 방지는 동일 주문번호와 지원하는 결제 흐름을 전제로 합니다. DB 제약은 로컬 결제 기록의 중복을 막으며, 외부 승인의 결과는 토스 응답·조회와 대조합니다.
- “PG 재호출 시에도 같은 멱등키 사용”: 현재 서비스는 동일 결제 키의 재요청이나 복구 작업에서 승인을 다시 요청하지 않습니다. 저장 결과를 반환하거나 상태를 조회합니다.
- “배송·혜택 등 후속 작업도 주문 기준으로 한 번만 시작됩니다”: 배송·혜택 처리는 구현되어 있지 않으며, 후속 작업의 중복 방지도 제공하지 않습니다.

이미지는 당시 자료를 보존하기 위한 것으로, 신규 연동이나 운영 절차의 기준으로 사용하지 않습니다.
